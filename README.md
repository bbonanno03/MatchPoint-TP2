# MatchPoint - TP Final Taller de Programacion 2

Sistema de reservas de canchas de padel y tenis con arquitectura Cliente/Servidor.

- `client/`: frontend en Vue 3, importado del TP de PNT2 (https://github.com/bbonanno03/PNT2-MatchPoint, repo archivado).
- `server/`: API REST en Node.js + Express (lo que se evalua en Taller 2).
